# AI 라켓·거트 궁합 분석기

배드민턴 동호인이 써 본 라켓·거트 후기("헤드가 무거워서 손목이 아팠어요", "거트가 금방 끊어져요")를 AI가 장비 스펙으로 번역하고, 실제 판매 라켓 69종(+단종 12종 참고)과 거트 16종 중 몸·플레이 스타일·후기에 맞는 **라켓 + 거트 + 텐션 조합**을 추천하는 웹 앱입니다.

머신러닝 AI 앱 개발 프로젝트 · 한국교통대학교 기계공학과 김민준 (1인 프로젝트)

- 실행 중인 앱 (누구나 로그인 없이 사용): https://racket-fitlast.vercel.app
- claude.ai 아티팩트 버전 (AI 실험실·피드백 저장 기능 포함, Claude 로그인 필요): https://claude.ai/artifact/HmqESrTm4rCDP1BARtJ9vW
- 범위: 라켓 추천을 먼저 완성한 뒤(기획서의 위험 관리 계획), 사용자 테스트 준비 단계에서 거트 추천(16종)과 예산·지금 텐션 입력을 추가했습니다.

## 핵심 기능 3개

1. **후기 분석 (AI ①):** 자유롭게 쓴 후기 → 선호 스펙 JSON (밸런스·강성·무게 −1~1, 거트 반발·컨트롤·내구 0~1, 텐션 −3~3lbs, 만족·불만 라켓·거트, 근거 문구)
2. **라켓·거트 추천 (점수 계산):** 신체 조건(성별 평균 대비 손 크기·악력, 구력), 플레이 스타일, 계절·거트 교체 주기·지금 텐션·예산, 선호 스펙으로 목표를 정하고 라켓 69종·거트 16종과 비교해 순위와 텐션 범위를 계산. 써 본 라켓(단종 포함)을 고르면 그 사양을 기준점으로 삼아 대체 라켓도 찾습니다.
3. **근거 설명 (AI ②):** 조건·후기와 추천 결과(라켓·거트·텐션)를 연결해 이유를 설명. 화면에 "AI가 생성한 내용"으로 표시합니다.

검증용 화면 2개: `#lab` AI 실험실(프롬프트·모델 비교), `#check` 편향 점검(가상 사용자 1,701명: 라켓·거트 1순위 분포).

## 실행 방법

### 1. 웹사이트로 배포 (누구나 링크로 사용, AI 포함) — 사용자 테스트용

`index.html`(화면)과 `api/ai.js`(AI 호출 서버 함수)를 Vercel에 올리면 `https://○○○.vercel.app` 주소가 생기고, 친구들은 계정 없이 그 링크로 바로 씁니다. API 키는 코드가 아니라 Vercel 환경 변수에만 넣습니다.

**① AI API 키 받기 (둘 중 하나)**

| | 구글 Gemini (추천: 무료) | Anthropic Claude (유료) |
| --- | --- | --- |
| 받는 곳 | aistudio.google.com → Get API key | console.anthropic.com → API Keys |
| 비용 | 무료 등급으로 충분 (카드 불필요) | 선불 크레딧 필요 (테스트 몇십 번은 몇백 원 수준) |
| 쓰는 모델 | gemini-3.5-flash-lite (quick) / gemini-3.8-flash (default) | claude-haiku-5-5 (quick) / claude-sonnet-5-5 (default) |
| 주의 | 무료 등급은 보낸 내용이 구글 제품 개선에 쓰일 수 있음 → 후기에 개인정보를 적지 않도록 앱에 안내함. API 이용은 만 18세 이상 | — |

**② GitHub에 올리기:** github.com에서 새 저장소(New repository)를 만들고 "uploading an existing file"로 이 폴더의 파일을 모두 끌어다 놓은 뒤 Commit. (`.env.example`은 올려도 되지만 실제 키가 든 파일은 절대 올리지 마세요.)

**③ Vercel에 배포:** vercel.com에 GitHub 계정으로 가입 → Add New → Project → 방금 만든 저장소 Import → **Environment Variables**에 아래를 넣고 → Deploy.

| 이름 | 값 |
| --- | --- |
| `GEMINI_API_KEY` (또는 `ANTHROPIC_API_KEY`) | ①에서 받은 키 |
| `ACCESS_CODE` (선택, 권장) | 아무 단어 (예: `badminton2026`). 넣으면 이 코드가 붙은 링크로 연 사람만 AI를 쓸 수 있어 키가 남용되지 않습니다 |

**④ 친구에게 보낼 링크:** `https://○○○.vercel.app/?code=badminton2026` (ACCESS_CODE를 안 넣었으면 `?code=` 부분 없이).

**⑤ 설문 연결:** 분석이 끝나면 결과 아래에 "1분 설문"이 나오고, 응답은 구글 시트에 바로 쌓입니다. `google-apps-script/설문수집_웹앱.gs`를 script.google.com에 붙여넣어 `setup` 실행 → 웹 앱으로 배포(실행: 나, 액세스: 모든 사용자)한 뒤, 나온 URL을 `index.html`의 `SHEET_URL`에 넣습니다. (구글 폼을 쓰고 싶으면 `SURVEY_URL`에 폼 링크를 넣으면 버튼으로 연결됩니다.)

배포 후 "AI 실험실"(`/#lab`)도 이 서버로 실행되므로, 같은 주소에서 프롬프트·모델 비교 실험을 돌릴 수 있습니다.

### 2. claude.ai에서 실행 (만든 사람용)

https://claude.ai/artifact/HmqESrTm4rCDP1BARtJ9vW — claude.ai에 로그인한 상태로 엽니다. 같은 `index.html`이 claude.ai 안에서는 아티팩트의 AI 기능을 씁니다.

### 3. 내 컴퓨터에서 파일로 실행 (AI 없이)

`index.html`을 브라우저로 열면 됩니다. AI를 부를 수 없어서 후기 해석과 설명을 기본 규칙(키워드)으로 대신하며, 화면에 그 사실을 안내합니다.

### 4. 점검 스크립트

```bash
pip install playwright
playwright install chromium
python tests/run_checks.py
```

예시 조건 4개의 추천 결과(라켓·거트·텐션), AI 실험실 기준선(기본 규칙 60%), 가상 사용자 1,701명(손 3 × 악력 3 × 구력 3 × 스타일 7 × 계절 3 × 교체 주기 3)의 오류 수와 라켓·거트 1순위 분포를 출력합니다.

## 코드 안내 (index.html의 `<script>`)

| 함수·상수 | 하는 일 |
| --- | --- |
| `RACKETS` | 라켓 DB. `bal` 1 헤드라이트~5 헤드헤비, `flex` 1 매우 유연~5 매우 딱딱, `ws` 판매 무게 옵션, `est` 추정값 여부, `id` 출처 상세 페이지 번호 |
| `readForm()` | 입력 화면 값 읽기 |
| `specPrompt()` | AI ① 프롬프트: 값의 뜻·범위, 체감 표현 예시, 추측 금지, DB 이름 목록, 후기 속 지시 무시 |
| `askJSON()` | AI 호출. 8초 넘으면 안내, 30초면 중단 |
| `normalizeSpec()` | AI 출력 검증: 범위 밖 값 자르기, DB에 없는 라켓 이름 버리기 |
| `ruleParse()` | AI 실패 시 쓰는 키워드 규칙 해석 |
| `STRINGS` | 거트 DB. `rep`·`dur`·`ctrl`은 제조사 발표 점수 그대로, `gauge` 굵기, `hard` 타구감, `tier` 가격대(대략), `est` 추정 여부, `src` 출처 |
| `computeTarget()` | 신체 조건·스타일·선호 스펙 → 목표 밸런스·강성·무게, 거트에서 중요하게 볼 비율(반발·컨트롤·내구)·권장 굵기·타구감, 텐션(악력 22/24/26 + 구력 ±1 + 계절 ±1 + 후기 체감, 지금 텐션을 넣으면 그 값에서 출발) |
| `scoreRackets()` | 목표와의 거리로 점수: `100 − 24 × (0.45·밸런스차 + 0.35·강성차 + 0.2·무게차)`, 불만 라켓 −30, 만족 +4, 추정 사양 −3. 동점이면 구력에 맞는 가격대(입문 9만·중급 17만·상급 26만 원)에 가까운 모델 먼저 |
| `scoreStrings()` | 거트 점수: "점수가 높을수록 좋다"가 아니라 내가 중요하게 보는 비율과 거트의 성격(반발·컨트롤·내구 비율)이 닮은 정도 + 굵기·타구감 일치 + 구력에 맞는 가격대. 제조사마다 점수 범위가 달라 브랜드별 최고점으로 환산 |
| `recommend()` | 예산을 넣으면 예산 안 라켓만 순위에 올리고, 예산 밖에 더 잘 맞는 라켓이 있으면 따로 알려 줌 |
| `groupBySpec()` | 사양이 같은 라켓을 한 묶음으로 (동점이면 구력에 맞는 가격대 모델이 대표) |
| `explainPrompt()` / `ruleExplain()` | AI ② 프롬프트 / 실패 시 기본 문장 |
| `analyze()` | 전체 흐름: 후기 분석 → 점수 계산 → 근거 설명, 단계별 실패 처리 |
| `serverSample()` | 웹사이트 버전에서 `/api/ai` 서버 함수 호출 (claude.ai 안에서는 아티팩트 AI 기능 사용) |
| `SURVEY_URL` | 사용자 테스트 설문(구글 폼) 주소 |
| `saveFeedback()` / `loadFeedback()` | claude.ai 버전의 앱 안 피드백 저장·모아보기 |
| `runLab()` | AI 실험실: 조건 4개 × 후기 12개 실행, 방향 정확도·이름 인식·JSON 성공률·응답 시간·공격 방어 채점, 요청 한도에 걸리면 기다렸다 재시도 |
| `simulateAll()` / `runCheck()` | 가상 사용자 1,701명 시뮬레이션과 편향 점검 (라켓·거트 1순위 분포) |
| `SHEET_URL` / `saveFeedback()` | 앱 안 1분 설문을 구글 시트 수집기로 전송 (동의 체크 필수) |
| `shareResult()` | 결과 요약 문구를 공유·복사 |

## 데이터 출처

라켓 사양(무게 옵션, 밸런스, 샤프트 강성, 가격)은 [배드민턴마켓](https://www.badmintonmarket.co.kr) 상품 상세 페이지의 글 설명과 상세 이미지 속 사양표에서 2026-11-15에 옮긴 사실 정보입니다. 이미지와 문구는 앱에 쓰지 않았습니다. 라켓마다 상세 페이지 링크가 `data/rackets.csv`와 앱의 "DB 보기"에 있습니다.

단종 라켓 12종은 판매처(BadmintonBay, Tennisnuts, Racquetguys 등)에 남아 있는 제조사 표기(밸런스·강성·무게)를 같은 1~5 점수로 바꿨고, 모델마다 출처 링크를 `data/rackets_discontinued.csv`에 적었습니다. 단종 라켓은 살 수 없으므로 추천 목록에는 나오지 않고, 사용자가 써 본 라켓의 사양을 알아내 "대체 라켓"을 찾는 데만 씁니다.

**거트 16종**은 제조사가 발표한 점수(반발력·내구성·컨트롤)와 굵기를 그대로 썼습니다. 요넥스 10종은 요넥스 카탈로그 점수(6~11점)를 정리한 판매처 표, 빅터 3종은 빅터 VBS 시리즈 발표 점수(6~9점), 타구감은 빅터 공식 설명과 판매처 표기를 따랐습니다. 리닝 3종은 숫자 점수를 찾지 못해 굵기와 분류(반발형·균형형·내구형)로 추정했고 앱에 "일부 사양 추정"으로 표시합니다. 거트마다 출처 링크는 `data/strings.csv`와 앱의 "DB 보기"에 있습니다. 제조사마다 점수 기준이 달라 브랜드 간 비교는 참고용입니다. 겨울에 텐션을 1lbs 낮추는 것은 "추운 곳에서는 줄 탄성이 떨어져 조금 낮게 맨다"는 스트링 업계의 일반적인 조언을 따른 것입니다.

- 1차(28종): 요넥스 11종은 대표 모델 직접 선정, 빅터 10종·리닝 7종은 판매순 상위 (색상만 다른 모델 제외)
- 2차(41종 추가): 같은 사이트에서 하위 등급(게임·플레이·투어)과 입문용, 판매 중인 다른 시리즈를 추가. 상세 이미지의 사양표(무게·밸런스·샤프트 탄성)를 글자 인식(OCR)으로 읽고, 애매한 30종은 사양표 이미지를 직접 확인했습니다.
- 현재 구성: 요넥스 27종, 빅터 26종, 리닝 16종. 밸런스 대신 "공격형·컨트롤형·스피드형" 같은 타입만 적혀 있거나 강성 표기가 없는 19종은 점수를 추정했고 앱에 "일부 사양 추정"으로 표시합니다.
- 편향 점검에서 발견해 고친 점: 사양이 같은 라켓이 여럿일 때 "가장 싼 모델"을 대표로 보여 줬더니 한 브랜드가 1순위의 90%를 차지했습니다. 대표를 "구력에 맞는 가격대에 가까운 모델"로 바꾸고, 스타일에 따른 밸런스 이동량을 제조사의 3단계 표기(헤드라이트·이븐·헤드헤비)에 맞게 키웠습니다. 그래도 빅터가 1순위의 약 72%입니다(요넥스는 헤드헤비·헤드라이트 양 끝에 몰려 있고, 가운데 사양대는 빅터가 많기 때문). 점수 계산에 브랜드는 쓰지 않습니다.

`data/lab_cases.json`과 편향 점검의 가상 사용자는 개발 검증용으로 만든 데이터이며 실제 사람의 응답이 아닙니다.
